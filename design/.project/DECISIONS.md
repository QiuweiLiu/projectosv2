## 2026-11-03 — D004：阶段性结论（受控 pilot）
- 决定：Kernel 判定为"受控 pilot 可用"——单机、单用户、有人值守、3–10 任务 DAG。
- 依据：真实 AO + OpenCode 2 + DeepSeek 的 A∥B→C、P1 阻断、定向复审闭环；52 项测试 + race；最近 5 次真实运行连续全绿；独立审查 23 项已处置。
- 影响：不宣称生产可用；reviewer 无量化基线、token 为估算、多机不做、跨平台未测。判定与升级条件见 docs/readiness.md。
- 状态：有效，等待 pilot 反馈。

## 2026-11-05 — P2：多目标做在 Workspace 层，不改 Kernel 单目标假设
- 每个目标一个 `projects/<id>/`，独立 DB/锁/work/out；一个 serve 聚合，可并行。
- 执行前审批只放行高风险任务与 command 校验，不做逐工具拦截；command 仍不是沙箱。
- 会话续跑复用 provider session，但每次尝试仍用新工作目录。
- 文本 diff 对比最新尝试 vs 上次交付/上一尝试；二进制只标有变化。
- macOS 外壳用 Objective-C + WKWebView，不用 Electron；退出只停自己启动的 HTTP 客户端。
